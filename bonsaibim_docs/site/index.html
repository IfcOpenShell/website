Bonsai documentation

Free and open source OpenBIM tools for IFC, built on IfcOpenShell.

Bonsai Studio

Native IFC authoring in Blender. Model, document and analyse buildings and infrastructure.

Bonsai Viewer

A fast desktop viewer for opening, federating and reviewing large IFC models.

Bonsai Web

View and share IFC models in the browser. Documentation coming soon.

Looking for the latest development builds? See the unstable documentation for Bonsai Studio and Bonsai Viewer.
